# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

OpenCookie — a self-serve Cookie Consent Management Platform (CMP). Laravel 13 + Inertia + React 19,
GDPR-first. Website owners register a domain, verify ownership, scan it for cookies, configure a
consent banner, and embed a standalone JS SDK that gates tracking scripts on visitor consent.

`docs/` holds the authoritative functional spec, technical spec, data model, and user stories
(`docs/user-stories/*.md`). Code comments reference user-story IDs (`US-SCAN-5`, `US-ADMIN-3`,
`US-LOG-4`) — when touching a feature, read the matching story file first.

## Commands

```bash
composer dev            # server + queue worker + pail logs + vite, all concurrent
composer test           # config:clear + pint --test + artisan test
composer ci:check       # eslint + prettier + tsc + test (what CI runs)
composer lint           # pint --parallel (PHP autofix)

php artisan test --filter=AdminTest          # single test file
php artisan test tests/Feature/AdminTest.php # same, by path

npm run build:sdk       # REQUIRED after editing resources/sdk/cmp.ts → public/sdk/v1/cmp.js
npm run types:check     # tsc --noEmit
npm run lint            # eslint --fix
npm run format          # prettier --write resources/
```

`resources/js/{actions,routes,wayfinder}` are **generated by Wayfinder** at Vite build/dev time and
gitignored. Never edit them by hand; they regenerate from PHP route + controller signatures.

## Architecture

### Two request surfaces

1. **Dashboard** (`routes/web.php`) — session + CSRF, Inertia/React pages in `resources/js/pages/`.
2. **Public Consent Ingest API** (`routes/ingest.php`, prefix `/v1/c`, names `ingest.*`) — registered
   in `bootstrap/app.php` outside the `web` group, so it is **stateless: no session, no CSRF**.
   Rate-limited by the `ingest` limiter (per-IP + per-domain, defined in `AppServiceProvider`).
   Consumed by the SDK on customer sites. Adding a route here means adding it to that `then:` group,
   not to `web.php`.

### Consent SDK

`resources/sdk/cmp.ts` is framework-free vanilla TS, built by a **separate Vite config**
(`vite.sdk.config.ts`, IIFE, `es2018`) into `public/sdk/v1/cmp.js` — a committed static asset, not
part of the app bundle. It renders the banner, gates `<script type="text/plain"
data-cmp-category="...">` tags, emits Google Consent Mode v2, and talks to the ingest API. Changes
here require `npm run build:sdk` and, in production, a CDN purge.

### Scanning

`SiteScanner` interface with two implementations, bound in `AppServiceProvider::register()` by
`config('scanner.driver')`:

- `HttpSiteScanner` — no JS, reads `Set-Cookie` + third-party `<script src>`. Default, used in tests/CI.
- `PlaywrightSiteScanner` — shells out to `scanner/crawl.mjs` (Node + Chromium), captures
  client-side cookies and storage. Fails the scan loudly rather than returning partial data.

Scans run through `RunScanJob` (queued). Page limit comes from the owner's tier
(`max_scan_pages`), falling back to `RunScanJob::DEFAULT_PAGE_LIMIT`. `RunScanJob::$timeout` must
stay above `config('scanner.playwright.timeout')` or the worker SIGALRM-kills the job mid-crawl and
the scan is stuck "running".

Cookie category resolution order in `RunScanJob`: **per-domain `CookieOverride` → `CookieClassifier`
(the `cookie_classifications` table, seeded by `cookies:import-ocd` from the Open Cookie Database) →
built-in static fallback map**. Preserve that precedence.

### Roles, tiers, authorization

- `spatie/laravel-permission`. Only role today is `App\Enums\Role::SuperAdmin` (`super_admin`),
  seeded by `RolesSeeder`, granted via `php artisan make:super-admin`.
- `AppServiceProvider::boot()` registers `Gate::before` — **super admins bypass every policy**.
  Owner policies (`DomainPolicy`, `CookiePolicy`) can therefore stay a plain `user_id` comparison.
- Admin area is `routes/web.php` under `role:super_admin` middleware, prefix `admin`, name `admin.`,
  controllers in `app/Http/Controllers/Admin/`.
- `Tier` (plan limits: `max_domains`, `max_scan_pages`, `monthly_pageview_cap`,
  `scheduled_scans_allowed`). Exactly one tier has `is_default = true` — `TierController` enforces
  that invariant, and `Tier::default()` / `User::resolveTier()` depend on it existing.
- `HandleInertiaRequests` shares `auth.user` and `auth.isSuperAdmin` to every page.

### Domain identity

`Domain::getRouteKeyName()` returns `domain_uid` — routes and the SDK bind by the public uid, never
the sequential id. Use `domain_uid` in any new route or public payload.

### Compliance evaluation

`App\Services\DomainCompliance` is the single source of truth for the compliance checklist, shared by
the owner dashboard and the admin overview so both judge identically. Add checks there, not in a
controller.

### Scheduling

`routes/console.php`: weekly/monthly `scans:dispatch-scheduled`, plus a daily
`PurgeExpiredConsentJob` enforcing the fixed 24-month consent retention.

## Testing

Pest. `tests/Pest.php` applies `RefreshDatabase` and seeds `RolesSeeder` + `TiersSeeder` before every
Feature test — the `super_admin` role and the default tier are platform invariants the app assumes,
so don't re-seed them in individual tests. SQLite `:memory:` via `phpunit.xml`; `SCANNER_DRIVER`
stays `http` in tests.

## Conventions

- PHP style is Pint (`pint.json`); frontend is Prettier + ESLint + `prettier-plugin-tailwindcss`.
  `composer ci:check` before considering work done.
- Enums live in `app/Enums/` and are used as Eloquent casts, not raw strings.
- Validation belongs in `app/Http/Requests/` form requests, not inline in controllers.
- `Date::use(CarbonImmutable::class)` is set globally — date values are immutable.
